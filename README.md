# Royals Pressure Lab

Interactive dashboard for the Rajasthan Royals SupeRR Selector (Season 2) challenge: who performs best when the match is on the line.

It combines the **report** (top-10 batters and bowlers, ratings, tiers, re-run stability, scouting notes, best pressure knocks, 2027 auction pool) with the **data pack** (IPL + T20I ball-by-ball, 2022-26, each ball tagged pressure or normal) so every chart reacts to the filters.

## Views
- **Player**: rating, tier, season trend, phase split, rank security, scouting notes, best knocks
- **Rankings**: top 10 with rating bars, likely rank ranges, robustness table
- **Explorer**: every qualifying player, normal vs pressure scatter, biggest lifts, sortable table
- **Head to head**: percentile radar, phase bars, stat table
- **Auction pool**: best pressure performers not retained for 2027
- **Method**: how the rating is built, worked example

Filters: batting/bowling, IPL/T20I, season, phase, minimum balls. Light and dark themes. Phone, tablet and desktop.

## Run
Static site, no build. Open `index.html` or serve the folder.
